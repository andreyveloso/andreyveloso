## 💼 Projeto em destaque

### [Modelagem de Dados — ERP Multiplikar Automóveis](https://github.com/andreyveloso/modelagem-banco-multiplikar-automoveis)

**Objetivo:** modelar conceitualmente os dados e processos de uma empresa do setor automotivo como base para um sistema ERP.

**Minha contribuição:** caracterização da empresa, levantamento de problemas, requisitos funcionais e não funcionais, identificação de entidades e relacionamentos, além da conclusão do projeto.

**Conceitos e ferramentas:** modelagem de dados, regras de negócio, diagrama entidade-relacionamento, Draw.io e GitHub.
